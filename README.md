# 🤡 Experimental Sites

Silly, playful, experimental websites built with Matter.js + Tone.js physics + sound.

Inspired by [dblodorn/instruments](https://github.com/dblodorn/instruments) and the experimental projects on [dmbk.io](https://dmbk.io).

Each site is its own git branch. Never merged to main — just chaos.

## Sites

| Branch | Description |
|--------|-------------|
| `exp-clickholes-redux` | Click to create wormholes that suck balls in |
| `exp-chaos10` | 10 chaotic physics elements colliding with sound |
| `exp-color-chord` | Color-coded balls playing ambient chords |
| `exp-gravity-flip` | Flip gravity, balls go wild |
| `exp-119-paintings` | 119 swatches each playing a different tone |
